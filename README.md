# Зенит Аланья — концепция сайта

[Открыть сайт](https://safal207.github.io/zenit-alanya-site/)

Независимая концепция для обсуждения с клубом, не официальный сайт.

В репозитории хранится готовая сборка: 78 файлов сайта в `site.zip` и список их контрольных сумм в `site-manifest.json`. Публикация проверяет целостность каждого файла и размещает сборку в GitHub Pages.

На главной — фоновый ролик с автоматическим зацикленным воспроизведением без звука. Есть светлая и тёмная темы, история вымышленного игрока, обращения и контакты школы.

Права на материалы и лицензии сторонних библиотек указаны в самом сайте и соответствующих файлах сборки.
